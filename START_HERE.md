# 🚀 Quick Start Guide

## Option 1: View Immediately (No Installation)

**Just double-click this file:**
```
standalone.html
```

This works instantly in any browser! No Node.js or npm required.

---

## Option 2: Full React Development (Requires Node.js)

### Prerequisites
- Node.js installed (download from https://nodejs.org/)

### Steps:

**1. Open PowerShell in this folder**
   - Hold Shift + Right-click in this folder
   - Select "Open PowerShell window here"

**2. Install dependencies:**
```powershell
npm install
```

**3. Start the app:**
```powershell
npm run dev
```

**4. Open browser:**
   - Automatic: Browser opens at http://localhost:3000
   - Manual: Visit http://localhost:3000
