## 🎨 Customization Options

### Change Workflow Apps

Edit `Hero.jsx` to change Gmail/Sheets:

```jsx
// Replace Gmail with Slack
<svg viewBox="0 0 24 24">
  {/* Your Slack icon SVG */}
</svg>
```

### Adjust Pink Intensity

Edit `Hero.css`:

```css
background: linear-gradient(180deg, 
  #ffffff 0%,     /* White */
  #fef5f8 30%,    /* Lighter pink */
  #fef0f5 60%,    /* Adjust this */
  #ffffff 100%
);
```

### Change Hub Color

```css
.node-icon.flowmitra {
  background: linear-gradient(135deg, 
    #your-color-1 0%, 
    #your-color-2 100%
  );
}
```
