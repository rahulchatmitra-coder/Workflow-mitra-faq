# Playwright CLI Reference

Playwright CLI provides a fast command-line interface for browser automation.

## Common Commands
- **Open URL**: `playwright-cli open <url>`
- **Navigate**: `playwright-cli goto <url>`
- **Snapshot Page**: `playwright-cli snapshot`
- **Click Element**: `playwright-cli click <target>`
- **Fill Input**: `playwright-cli fill <target> <text>`
- **Screenshot**: `playwright-cli screenshot [target]`
- **Run Playwright Code**: `playwright-cli run-code [code]`
- **Close Browser**: `playwright-cli close`
- **Clean Session**: `playwright-cli close-all`
